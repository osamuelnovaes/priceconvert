# PriceConvert - Sistema de Precificação com Conversão de Moeda

Sistema web para calculadora de precificação de serviços da empresa, com conversão de valores em reais (BRL) para múltiplas moedas estrangeiras em tempo real.

## Funcionalidades

- Seleção de 10 tipos de serviços com faixas de valores específicas
- Conversão em tempo real via API de câmbio
- 6 moedas disponíveis: USD, EUR, GBP, CAD, AUD, JPY
- Alertas para valores fora da faixa permitida
- Design responsivo
- Tratamento de erros com API fallback

## Como Usar

1. Selecione o tipo de serviço
2. Informe o valor em Reais (R$)
3. Selecione a moeda de conversão
4. Clique em "Calcular Conversão"

## Deploy

Este projeto está configurado para GitHub Pages. O deploy é feito automaticamente a cada push para a branch `main`.

## Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)
- API de Câmbio: AwesomeAPI / ExchangeRate-API
